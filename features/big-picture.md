# Big Picture Mode

Big Picture Mode is Ascendara's controller-first, full-screen interface, built for playing from the couch. You can browse your library, launch games, search the catalog, follow downloads, and play your Retro games without a mouse.

## Entering Big Picture Mode

- Connect a controller. When Ascendara detects one, it asks whether you'd like to switch to Big Picture Mode.
- Select **Enter Big Picture** in the title bar or in **Settings** → **Big Picture Mode**.
- Open the command palette (**Ctrl+K**) and select **Enter Big Picture Mode**.

To leave, open the menu and select **Exit Big Picture**.

## Controllers and Keyboard

Big Picture Mode works with Xbox, PlayStation, and generic controllers, and with a keyboard. Set your **Controller Type** in **Settings** → **Big Picture Mode** so the on-screen button prompts match your controller.

When you need to type, such as when searching, Big Picture Mode shows a virtual keyboard. Choose a **QWERTY** or **AZERTY** **Keyboard Layout** in Settings.

## What You Can Do

- **Home**: Recently played games and quick access to your library. Choose between the full **Ascendara** dashboard and the **Classic** carousel with **Home style** in Big Picture preferences.
- **Library**: Browse and launch your installed games, and view game details, screenshots, and media.
- **Search**: Browse the game catalog, see game details, and add games to Play Later.
- **Downloads**: Follow active and queued downloads, and stop or kill a download.
- **Retro**: Play games from your [Ascendara Retro](/docs/features/retro) library and set up consoles.
- **Cloud**: Your Ascend cloud library and cloud saves.
- **Index**: Manage [your game index](/docs/features/refreshing-index), including **Keep Index Up to Date**.
- **Preferences**: Big Picture settings such as controller type, keyboard layout, and home style.
- **Power**: Return to the desktop interface, exit Ascendara, or shut down your computer.

From a game's page you can also play with a trainer, open the mod manager, and back up or restore saves. For advanced backup management, use the regular Library screen.

## Downloading in Big Picture Mode

Games that support seamless downloads (GoFile and PixelDrain) download directly in Big Picture Mode. If more than one provider is available, choose one. Other download methods need a browser, so Ascendara asks you to exit Big Picture Mode and continue in the regular interface.

The usual download queue limits apply. See [Downloading Games](/docs/features/downloading#download-queue).

## Things That Need a Mouse

A few actions still need a mouse or touchpad:

- Browsing for a game executable in the executable manager
- Some file and folder pickers

Ascendara tells you when a mouse is required.
