# Staying Safe on Ascendara

Understanding the risks and protecting yourself online is essential. Please note that Ascendara is not responsible for any damage that you do to your device.

## Ascendara Download Manager

Ascendara has its own download manager that downloads, extracts, verifies, and installs games for you. Some games support seamless downloads that need no browser at all, while others require you to visit the file host and send the real download to Ascendara.

## Download Process

### Seamless Downloads
Games from supported providers (GoFile and PixelDrain) can be downloaded directly in Ascendara. You never visit the file host, so there are no ads or fake buttons to avoid.

### Browser Downloads
For other providers, you open the file host page in your browser and start the download yourself. Navigate the page carefully until you reach the real download, then let the Download Handler extension send it to Ascendara, or copy the direct download link manually.

### Download Handler Extension
The Ascendara Download Handler extension captures the real download when it starts and sends the file link straight to Ascendara, so the file is downloaded and installed by Ascendara instead of your browser.

## Watch Out For

### Deceptive Download Buttons
File hosts display multiple fake "Download Now" buttons. Be patient and wait for the real download to become available after the countdown.

### Misleading Pop-ups
Ignore pop-ups claiming you need additional software or updates. These are scams trying to install unwanted programs or malware on your system.

### Files That Are Too Small
The file you download should be about the size shown on the game's page in Ascendara. Be suspicious of tiny files, especially ones only a few KB in size, or files ending in `.exe`, `.msi`, or `.bat` when you expected an archive.

## Common Examples

### File Host Page
A typical file host page might show:

❌ Multiple colorful "Download Now" buttons (These are ads)  
❌ "Your download is ready!" pop-ups with fake download buttons  
❌ "Install Download Manager" or "Update Required" pop-ups  
✅ A countdown timer (Usually legitimate - wait for it)  
✅ Small, plain "Download" link after countdown (Usually legitimate)  

### Red Flags
Signs that something is probably an ad or scam:

⚠️ Large, colorful buttons appearing before the countdown ends  
⚠️ Pop-ups asking you to install additional software  
⚠️ Multiple download buttons visible at the same time  
⚠️ System alert style pop-ups claiming you need updates  

## Antivirus False Positives

Game files, especially online-fix and crack files, are often flagged as false positives by antivirus software and removed during or after installation. On Windows, Ascendara can exclude your download folders from Windows Defender: enable **Protect Directories from Defender** in **Settings**. This only affects Windows Defender. If you use another antivirus, add your download folders as exclusions in that antivirus yourself. Ascendara's [download folder check](/docs/features/downloading#download-folder-check) tests each download folder with a commonly flagged file, so you know whether your antivirus will interfere before you download a game.

Only exclude folders that you use for games, and only download from the providers listed in Ascendara.

## Stay Safe

Whether you use seamless downloads or the browser extension, always let Ascendara's download manager handle the actual download and installation.

> **Remember:** Never download or run any additional software suggested by file hosting sites. Ascendara is the only program you need to download and install your games.
